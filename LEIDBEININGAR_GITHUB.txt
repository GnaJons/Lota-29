LOTA 29 - VEFUR FYRIR GITHUB PAGES

1. Afþjappaðu ZIP-pakkanum.
2. Hladdu innihaldinu upp í GitHub-gagnasafnið þitt. Skráin index.html
   á að vera í rót útgáfumöppunnar, með PDF-skjölunum og formulublad.html.
   Ekki hlaða ZIP-skránni einni upp sem vefsíðu.
3. Í GitHub velurðu Settings > Pages. Undir Build and deployment velurðu
   Deploy from a branch og síðan greinina sem geymir skrárnar (oft main)
   og / (root). Vistaðu með Save.
4. Þegar GitHub hefur lokið birtingu birtist slóð vefsins í Pages-stillingunum.

Ef GitHub Pages er þegar virkt má setja allan pakkann í undirmöppu, t.d.
lota29. Tenglar milli HTML og PDF virka einnig þar, svo lengi sem skrárnar
halda sömu afstöðu hver til annarrar.

Í pakkanum:
- index.html: stytt vefhefti með sjö tímum, 33 sýnidæmum, gátlista og hugtökum.
- lota29-prent.pdf: 38 síðna prentútgáfa úr vefheftinu, Letter.
- formulublad.html: formúlublað og talnahús á sérstakri vefsíðu.
- rumfraediformulur-talnahus.pdf: upprunalega tveggja síðna fylgiblaðið, A4.
- rumfraediformulur-talnahus.tex: breytanlegur frumkóði fylgiblaðsins.
- myndir/: allar 19 nýju PNG-myndirnar. Mappan verður að fylgja index.html.
- myndbond/: 11 myndbönd og forsýningarmyndir. Öll mappan verður að fylgja vefnum.
- frumkodi/: upphaflegt LaTeX-leshefti, Overleaf-pakki og Python-skrár myndbandanna.
- kennari/: kennaranótur og kortlagning efnis við verkefnablöðin.
- .nojekyll: stilling fyrir beina birtingu þessara HTML-skráa.

Vefurinn þarfnast ekki uppsetningar eða viðbótarvefþjónustu. Stíll og
stærðfræði eru innbyggð í HTML. Nýju skýringarmyndirnar eru í myndir/. Hægt er að opna index.html
beint á tölvu til að skoða efnið fyrir birtingu.

Gátlistinn man merkingar á sama tæki í sama vafra þegar vafrinn leyfir
vistun. Merkingarnar samstillast ekki milli tækja. Í sumum vöfrum getur
vistun verið takmörkuð þegar HTML-skráin er opnuð beint af tölvu.

Prentaðu lesheftið úr lota29-prent.pdf. Formúlublaðið og talnahúsið eru
prentuð sérstaklega úr rumfraediformulur-talnahus.pdf (A4).

Vefurinn var prófaður staðbundið. Birting í þínu GitHub-gagnasafni er ekki
framkvæmd hér; hún tekur gildi þegar þú hleður skránum upp og virkjar Pages.

Opinberar leiðbeiningar GitHub:
https://docs.github.com/en/pages/quickstart
